# 프로젝트 개요

## 목적
광고주 랜딩페이지의 GTM, Google Ads, Naver WCS, 당근, Meta, TikTok 공통/전환 스크립트를 중앙 관리한다.

## 단계
1. 관리자 기본 UI 및 설정 모델
2. Firebase Auth, Firestore, 공개 설정 API
3. 매체별 SDK 어댑터, 문의 완료 이벤트
4. 사이트 등록 CLI 및 운영 배포
5. 진단·롤백·엑셀 업로드

## MVP 완료 조건
- [ ] 사이트 등록 및 중복 방지
- [ ] 관리자 인증/권한
- [ ] 6개 매체 공통 태그
- [ ] 전환 이벤트
- [ ] 공개 설정 API
- [ ] SDK 설치·호환성 검증
- [ ] 게시/롤백
- [ ] 중복 태그 제거 확인

## 비범위
임의 JS 원격 실행, 실제 광고 플랫폼 전환 집계 보장, MLeverage SDK 수정.
