# 4일차 — 사내 접근 제어 및 API 보호 설계

이 문서는 작업 계획입니다. 체크리스트는 해당 일차의 실제 검증 후 표시합니다.

## 개발 목표

Firebase Auth 로그인 UI 대신 사내 접근 게이트와 서버 검증 계약을 정한다.

## 구현 기능

- VPN/프록시/기존 게이트웨이 선택
- 운영자 컨텍스트
- CSRF·세션·권한 검사
