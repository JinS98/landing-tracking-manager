# 12일차 — 공개 설정 API

이 문서는 작업 계획입니다. 체크리스트는 해당 일차의 실제 검증 후 표시합니다.

## 개발 목표

SDK가 사이트별 게시본만 조회하는 별도 API를 구현한다.

## 구현 기능

- siteId 조회
- 공개 JSON
- ETag/TTL
- 비밀 필드 제거

## 수정 또는 생성할 파일

- functions/src/
- packages/tracking-core/src/index.ts
- docs/04-api-spec.md

## 구체적인 작업 순서

1. 게시본 투영
2. 서버/CDN 응답
3. 캐시 무효화
4. 미게시 404 처리

## 테스트 방법

- 초안·감사 로그 미노출
