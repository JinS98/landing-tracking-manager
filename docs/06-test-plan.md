# 테스트 계획과 완료 기준

## 지금 실행 가능한 검사

    npm run typecheck
    npm run build
    npm test
    npm run test:rules

`npm run test:rules`는 Firebase CLI와 Java 21이 설치된 환경에서 로컬 Firestore 에뮬레이터를 시작합니다. `demo-` 프로젝트만 사용하고 실제 Firebase에 접속하지 않습니다. 현재 익명 REST의 여섯 컬렉션 조회·목록·생성·수정·삭제 및 중첩 경로 거부 테스트 7개가 통과했습니다. 인증된 클라이언트, 서버 IAM, 실제 Rules 배포와 인덱스 빌드는 검증되지 않았습니다.

브라우저 데모 시나리오:

1. 로그인 화면 없이 대시보드 진입; 업체/사이트/활성 매체 수와 최근 이력 확인
2. 업체명·siteId·도메인 검색, 한 업체의 여러 사이트 선택
3. 가상 사이트 등록 후 동일 siteId 재등록 차단 확인
4. 매체별 공통 ID 입력, Naver 유입 도메인 필수값, Google Ads AW 형식 확인
5. 공통 매체가 없을 때 전환 추가 차단; 추가·수정·비활성화·제거 확인
6. 초안과 게시본 미리보기, 데모 게시, 변경 후 이전 버전 롤백, 이력 확인
7. 새로고침 후 데모 상태 초기화; Firebase/광고 플랫폼 네트워크 쓰기 없음 확인

현재 npm test(Node.js 22.14+)는 MVP 동작 3개와 서버 접근 검사 조합 함수의 모의 구현 시나리오 7개를 검사합니다. 후자는 실제 회사 게이트웨이나 HTTP API의 보안 검증을 뜻하지 않습니다.

## 운영 완료 기준

위 서버·SDK 항목이 통과하고 사내 접근 게이트, 운영 Firestore Rules, 실사이트 태그 인벤토리, 게시/롤백 절차가 검증되기 전에는 운영 배포 완료로 표시하지 않습니다. 현재 완료된 것은 메모리 데모 UI, SDK 공통 구조, MVP 테스트 3개·접근 계약 모의 테스트 7개·로컬 Rules 테스트 7개, 타입/빌드 검사입니다.
